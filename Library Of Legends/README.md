# 📖 Overview

Library Of Legends is a modular software platform designed for organizing, managing and publishing digital media collections.

Project Phoenix is the first official application built on top of the Library Of Legends Architecture Framework (LOAF).

The project is designed with long-term maintainability, scalability and documentation as its highest priorities.

---

# 🎯 Vision

Create a professional, modular and extensible media platform capable of managing:

- 🎬 Movies
- 📺 TV Series
- 🎵 Music
- 🎧 Audiobooks
- 📚 Books
- 📖 Comics
- 📰 Magazines
- 🎙 Podcasts
- 🧸 Children's Media

while remaining clean, maintainable and fully documented.
