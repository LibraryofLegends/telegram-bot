# 1. Purpose

The Project Templates establish the official foundation for creating all
future project artifacts within Library Of Legends.

Their purpose is to ensure that every new component follows the same
structure, documentation standard and architectural conventions from the
moment it is created.

---

# 2. Description

Project Templates provide standardized starting points for:

- Framework modules
- Features
- Providers
- Services
- Repositories
- Interfaces
- Enumerations
- Tests
- Documentation
- Policies
- Standards
- Workflows

Every new artifact shall originate from an official template.

---

# 3. Objectives

The Project Templates shall:

- standardize development
- reduce repetitive work
- improve maintainability
- increase documentation quality
- simplify onboarding
- guarantee architectural consistency

---

# 4. Scope

The templates apply to every repository artifact including:

- Source Code
- Documentation
- Policies
- Standards
- Workflows
- Tests
- Architecture Specifications

No manually created structure shall bypass the official templates.

# 13. Risks

Without official templates:

- inconsistent project structures emerge
- documentation quality decreases
- architectural standards drift over time
- development becomes slower
- maintenance effort increases

---

# 14. Lessons Learned

- Standardized templates significantly improve development efficiency.
- Consistency is easier to maintain than to restore.
- Documentation quality begins with a solid template.
- Every future component benefits from a common foundation.
- Architecture decisions should be embedded into templates rather than
  repeated manually.
