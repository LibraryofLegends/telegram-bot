# 1. Purpose

This standard defines the approved structure, formatting rules and quality requirements for documentation within the Library Of Legends Architecture Framework (LOAF).

Its objective is to ensure consistency, readability, maintainability and traceability across all controlled documents.

---

# 2. Scope

This standard applies to:

- Policies
- Standards
- Workflows
- RACI Matrices
- Role Definitions
- Specifications
- Templates
- Reports
- Governance Documents

---

# 3. Documentation Structure

Every controlled document shall contain:

- Document Metadata
- Title
- Table of Contents
- Main Content
- Related Documents
- References
- Revision History
- Approval Block

Documents shall follow the approved template.

---

# 4. Mandatory Metadata

Every document shall include:

- Document ID
- Title
- Version
- Status
- Classification
- Author
- Creation Date
- Last Updated
- Project Name

Metadata shall appear at the beginning of the document.

---

# 5. Formatting Rules

Documentation shall:

- use Markdown
- use hierarchical headings
- use consistent tables
- use ordered numbering
- use approved terminology
- avoid duplicated sections
- remain readable on desktop and mobile devices

---

# 6. Naming Conventions

Documents shall:

- use uppercase filenames
- separate words with underscores
- use descriptive names
- align filenames with Document IDs
- avoid abbreviations unless approved

Example:

DOCUMENTATION_STANDARD.md

---

# 7. Cross References

Documentation shall reference:

- related policies
- related workflows
- related standards
- related RACI matrices
- related specifications

Broken references are not permitted.

---

# 8. Quality Requirements

Documentation shall be:

- complete
- technically accurate
- internally consistent
- grammatically correct
- reviewed
- approved
- version controlled

---

# 9. Validation Requirements

Validation shall verify:

- metadata completeness
- formatting compliance
- reference integrity
- version consistency
- document classification
- approval status

Validation results shall be documented.
