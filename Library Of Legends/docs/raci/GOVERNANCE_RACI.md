# 1. Purpose

This document defines governance responsibilities across all core governance roles within the Library Of Legends Architecture Framework (LOAF).

The objective is to establish clear ownership, accountability and collaboration for governance processes.

---

# 2. Scope

The matrix applies to:

- Architecture Governance
- Documentation Governance
- Repository Governance
- Quality Governance
- Security Governance
- Release Governance
- AI Governance

---

# 3. RACI Definitions

| Code | Definition |
|------|------------|
| R | Responsible |
| A | Accountable |
| C | Consulted |
| I | Informed |

Rules:

- Exactly one Accountable role per activity.
- At least one Responsible role.
- Consulted roles provide expert input.
- Informed roles receive governance updates.

# 5. Decision Principles

Governance decisions shall:

- be documented
- be traceable
- follow established policies
- include stakeholder consultation where appropriate
- identify accountable ownership
- be reviewable through audits

---

# 6. Escalation Rules

Escalation levels:

Level 1

Role Owner

↓

Level 2

Architecture Owner

↓

Level 3

Governance Board

↓

Final Decision

Project Sponsor (if applicable)

Critical security incidents may bypass intermediate escalation levels.

---

# 7. Governance Guidelines

Governance activities shall:

- follow documented workflows
- maintain separation of duties
- preserve audit trails
- enforce policy compliance
- support continuous improvement
- minimize governance conflicts
