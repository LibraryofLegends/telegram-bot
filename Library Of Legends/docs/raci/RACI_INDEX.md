# 1. Purpose

This document serves as the master index for all Responsibility Assignment Matrix (RACI) documents within the Library Of Legends Architecture Framework (LOAF).

It provides a centralized overview of role responsibilities, decision authority and collaboration across the project.

---

# 2. Scope

The RACI family governs responsibility assignments for:

- Architecture
- Documentation
- Development
- Quality
- Security
- Releases
- Artificial Intelligence
- Repository Operations
- Project Governance

---

# 3. Objectives

The objectives of the RACI family are:

- define accountability
- eliminate responsibility conflicts
- standardize decision ownership
- improve collaboration
- simplify governance
- support auditing
- improve transparency

---

# 4. RACI Model

The framework adopts the standard RACI model.

| Code | Meaning |
|------|---------|
| R | Responsible |
| A | Accountable |
| C | Consulted |
| I | Informed |

Rules:

- Every activity shall have exactly one Accountable role.
- One or more Responsible roles may exist.
- Consulted roles provide expert input.
- Informed roles receive status updates.

---

# 5. RACI Principles

The following principles apply:

- Clear ownership
- Single accountability
- Transparent collaboration
- Documented decision-making
- Consistent governance
- Traceability
- Continuous review
