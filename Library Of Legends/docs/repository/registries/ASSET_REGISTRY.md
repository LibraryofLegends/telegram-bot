# 1. Purpose

The Asset Registry is the official inventory of every digital asset used throughout the Library Of Legends ecosystem.

Every reusable asset shall be uniquely registered.

---

# 2. Scope

Assets include

- Logos
- Icons
- Banners
- Wallpapers
- Backgrounds
- Splash Screens
- Fonts
- Videos
- Audio
- Templates
- Illustrations
- Documents
- Animations
- Marketing Material
- Brand Assets

---

# 3. Asset Categories

| Category | Description |
|----------|-------------|
| Branding | Logos & Identity |
| UI | Interface graphics |
| Telegram | Channel graphics |
| Marketing | Promotional material |
| Documentation | Embedded graphics |

| Audio | Music & Sounds |

# 4. Registry Structure

Every asset shall define

- Object ID
- Asset Name
- Category
- Format
- Resolution
- Owner
- License
- Source
- Repository Location
- Status
- Version
- Related Documents
