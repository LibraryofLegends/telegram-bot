# 1. Purpose

The Registry Index is the central entry point for every official registry within the Library Of Legends Architecture Framework (LOAF).

It provides a structured overview of all registries and defines how they relate to each other.

---

# 2. Registry Philosophy

Every permanent project object shall be registered.

Registries provide:

- discoverability
- traceability
- governance
- consistency
- automation support

A registry is the authoritative source for the objects it manages.

---

# 3. Registry Categories

The official registry categories are:

- Repository
- Documentation
- Packages
- Modules
- APIs
- Databases
- Tools
- Assets
- Templates
- Terminology
- Change Management

Additional registry categories may be introduced through an approved architecture decision (ADR).

# 5. Identifier Structure

Registry documents use the prefix:

LOL-REG

Numbering rules:

- unique
- sequential
- immutable
- never reused

---

# 6. Governance Rules

Every registry shall:

- have a documented owner
- define its scope
- maintain revision history
- reference related registries
- follow LLDS

Registry changes shall be documented and reviewed.

---

# 7. Maintenance Process

Registries shall be updated whenever:

- new components are introduced
- existing components change
- components are deprecated
- components are archived

Outdated registry information shall be corrected immediately.

---

# 8. Registry Lifecycle

Every registry entry follows:
