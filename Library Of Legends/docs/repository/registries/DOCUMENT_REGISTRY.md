# 1. Purpose

The Document Registry is the authoritative inventory of every official document within the Library Of Legends Architecture Framework (LOAF).

Every governed document shall be registered exactly once.

---

# 2. Registry Philosophy

The registry guarantees:

- discoverability
- consistency
- traceability
- governance
- version transparency

The registry shall always represent the current state of project documentation.

---

# 3. Registry Scope

The registry includes every official document belonging to:

- Foundation
- Repository
- Standards
- Architecture
- ADR
- Modules
- API
- Database
- Telegram
- Operations
- Releases
- Templates
- Registries
- Indexes

No official document exists outside this registry.

---

---

# 5. Document Lifecycle

Every document follows:

Draft

↓

Review

↓

Stable

↓

Deprecated

↓

Archived

Deleted documents remain reserved in the registry.

---

# 6. Registry Structure

Each registry entry shall contain:

- Document ID
- Document Name
- Version
- Category
- Owner
- Status
- Repository Path
- Related Documents
- Last Updated

---

# 7. Metadata Requirements

Every registered document shall include:

- unique identifier
- semantic version
- author
- creation date
- last modification date
- classification
- approval status

Metadata shall conform to LLDS.

---

# 8. Identifier Mapping

Identifiers shall be:

- permanent
- immutable
- globally unique
- human-readable

Identifier reuse is prohibited.

---

# 9. Governance Rules

Every document shall:

- follow LLDS
- have an assigned owner
- maintain revision history
- reference related documents
- pass quality review

---

# 10. Registry Maintenance

The registry shall be updated whenever:

- a document is created
- a document is renamed
- a document changes status
- a document is archived

Registry maintenance is mandatory.
