# 1. Purpose

The Repository Registry is the central inventory of the Library Of Legends repository.

It provides a single source of truth for all repository areas, ensuring consistency, traceability and maintainability.

---

# 2. Registry Philosophy

The registry shall:

- document every repository area
- provide unique identifiers
- support automation
- enable repository discovery
- simplify maintenance

No official repository component shall exist without being registered.

# 4. Repository Areas

Each repository area shall include:

- Owner
- Purpose
- Documentation
- Standards
- Dependencies
- Lifecycle Status

---

# 5. Registry Rules

Every registered area shall have:

- unique identifier
- official documentation
- responsible maintainer
- documented purpose
- current status

Identifiers shall never be reused.

# 7. Lifecycle

Every registry entry follows:

Planned

↓

Active

↓

Deprecated

↓

Archived

Repository history shall remain traceable.

---

# 8. Maintenance Process

The Repository Registry shall be updated whenever:

- a new repository area is created
- an area is renamed
- an area is deprecated
- structural changes occur

Every update shall be documented in the revision history.
