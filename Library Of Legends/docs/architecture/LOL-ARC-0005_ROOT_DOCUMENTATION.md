# 1. Purpose

This document defines the official documentation located in the repository root.

Its purpose is to ensure that every contributor immediately understands the project structure, licensing, configuration and project status.

---

# 2. Documentation Philosophy

Root documentation provides the first impression of the project.

Every document shall remain accurate, concise and continuously maintained.

The repository root shall expose only documentation that is useful for every contributor.

---

# 3. Root Documentation Files

```text

LICENSE
```

# 5. Documentation Rules

The following rules are mandatory.

- Documentation shall remain synchronized with the implementation.
- Obsolete information shall be removed.
- Every major repository change shall update the appropriate documentation.
- Root documentation shall remain concise and easy to navigate.
