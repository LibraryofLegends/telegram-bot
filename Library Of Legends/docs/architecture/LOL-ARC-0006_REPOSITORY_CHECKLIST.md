# 1. Purpose

This checklist defines the mandatory verification process before a repository phase is considered complete.

Its purpose is to ensure consistency, completeness and quality across the entire Library Of Legends platform.

No repository milestone shall be approved without completing this checklist.

---

# 2. Usage

This checklist shall be used:

- before completing a repository phase
- before creating a release
- after major architectural changes
- before deployment
- during repository reviews

Every item shall be verified before approval.

- [ ] Architecture Review completed
