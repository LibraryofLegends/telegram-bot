# 1. Purpose

This document defines the official templates used for all documentation
within Project Phoenix.

Its purpose is to ensure that every document follows a consistent
structure, making documentation easier to read, review and maintain.

---

# 2. Vision

Every document shall follow one official template appropriate for its
classification.

Templates shall provide consistency while remaining flexible enough for
future document types.

---

# 3. Standard Document Structure

Every document shall contain, where applicable:

- Title
- Metadata
- Table of Contents
- Purpose
- Scope
- Main Content
- Design Principles
- Revision History
- Approval Block

---

# 4. Mandatory Metadata

Every document shall include:

- Project
- Codename
- Document Name
- Document ID
- Version
- Status
- Classification

---

# 5. Section Guidelines

Sections shall:

- have a clear purpose
- avoid duplication
- follow logical ordering
- use consistent terminology
- remain concise and maintainable

---

# 6. Template Categories

Official templates include:

- Architecture Template
- Specification Template
- Standard Template
- Policy Template
- Workflow Template
- Passport Template
- Blueprint Template
- ADR Template
- Mapping Template

Additional templates shall be approved through Documentation Governance.

---

# 7. Naming Conventions

Template names shall:

- use descriptive titles
- follow uppercase file naming
- include official IDs where applicable
- remain consistent across the repository

---

# 8. Future Extensions

Future versions may support:

- automated template generation
- template validation
- documentation linting
- localization support
- interactive documentation
