# Vision

The Shared Kernel provides the common language, contracts and building
blocks used by every module of the Library Of Legends platform.

It shall become the single source of truth for identifiers, value
objects, entities and shared domain concepts.

# Success Criteria

The Shared Kernel is complete when:

- Every module shares the same domain language.
- All identifiers are type-safe.
- Value Objects are immutable.
- Base entities are reusable.
- Shared contracts are standardized.
