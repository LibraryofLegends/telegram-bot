# Purpose

This document defines the licensing policy for the Provider SDK and its
future provider implementations.

The licensing model ensures legal clarity for internal development,
third-party integrations and future plugin extensions.

---

# Current License

The Provider SDK is part of the Library Of Legends project.

Unless explicitly stated otherwise, all source code, documentation and
architectural specifications are subject to the project's primary
license.

---

# Third-Party Providers

Each external provider remains subject to its own license and terms of
service.

Examples include:

- TMDB
- OMDb
- IMDb
- TheTVDB
- FanArt.tv
- Telegram
- Cloudinary
- Supabase
- OpenAI
- Plex
- Jellyfin
- Emby

Integrating a provider does not transfer ownership or licensing rights.

---

# Plugin Licensing

Third-party provider plugins:

- Must clearly declare their license.
- Must declare copyright ownership.
- Must document external dependencies.
- Should be compatible with the Library Of Legends architecture.

---

# Open Source Components

Open source dependencies shall:

- Retain original license notices.
- Comply with their respective license obligations.
- Be documented in project dependency records.

---

# Future Licensing

The overall project license may evolve over time.

Future versions may define:

- Community Edition
- Professional Edition
- Enterprise Edition
- Commercial Plugin SDK

Such changes shall be documented through Architecture Decision Records
and project governance documentation.
