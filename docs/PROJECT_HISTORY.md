# Project Timeline

## 2026

### July

#### 2026-07-31

Project Phoenix officially started.

The following strategic decisions were made:

• Complete project rebuild.

• Adoption of a modular monorepo architecture.

• Documentation-first development workflow.

• Creation of the Library Of Legends Development Standard (LLDS).

• Introduction of unique File IDs.

• Introduction of unique Document IDs.

• Decision to use dedicated documentation files for JSON and other
configuration files.

• Architecture Decision Records (ADR) adopted as mandatory.

• Quality assurance integrated into every development step.

• Project Documentation Foundation (Package D0) created.
