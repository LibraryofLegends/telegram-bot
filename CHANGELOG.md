# Versioning Strategy

## Major

Breaking architectural changes.

Example:

1.0.0 → 2.0.0

---

## Minor

New functionality.

Example:

1.1.0 → 1.2.0

---

## Patch

Bug fixes and documentation improvements.

Example:

1.1.0 → 1.1.1

---

# Release Types

| Type | Description |
|------|-------------|
| Major | Architecture or platform changes |
| Minor | New modules or functionality |
| Patch | Fixes and improvements |
| Docs | Documentation updates |
| Security | Security improvements |
| Refactor | Internal code improvements |
