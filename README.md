# Library Of Legends — Project Phoenix

Clean restart of the Telegram media archive.

## Current scope

The first build contains only the foundation required for a stable Telegram bot:

- Telegraf Telegram integration
- PostgreSQL persistence
- TMDB client
- Movie/series filename parser
- Separate movie and series post builders
- Render HTTP health endpoint

SQLite, duplicate legacy builders, experimental framework modules, premium features, progress tracking and advanced Netflix UI are deliberately not included yet.
