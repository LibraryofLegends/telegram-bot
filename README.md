# Vision

Library Of Legends is being developed as a platform rather than a single application.

Telegram is the first official client.

Future clients may include:

- Telegram Userbot
- Dashboard
- REST API
- CLI
- Mobile Applications
- Web Applications

The architecture allows the platform to evolve without redesigning the core.
